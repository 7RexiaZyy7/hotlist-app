# 中文社交媒体爆款文案模板

## 一、标题公式

### 高点击率标题模板

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字+结果 | 数字 + 核心内容 + 结果 | 「28天涨粉1万，我做对了这3件事」 |
| 反常识 | 认知冲突 + 好奇心 | 「发了500篇笔记后，我发现小红书最不需要的就是干货」 |
| 场景代入 | 具体人物 + 具体场景 | 「月薪8000的北漂女孩，靠副业月入15000」 |
| 问题解决 | 直击痛点 + 解决方案 | 「为什么你的笔记没人看？90%的人犯了这个错误」 |
| 稀缺资源 | 稀缺性 + 价值承诺 | 「分享我用了3年的选题灵感库（附200个爆款方向）」 |
| 利益承诺 | 具体承诺 + 可信度 | 「月薪5k到2w，我只做对了这3件事」 |
| 数据背书 | 数据 + 结论 | 「亲测30款精华，这5款修复力TOP」 |
| 场景共鸣 | 场景 + 情绪 | 「凌晨2点的写字楼，90后在拼什么」 |

## 二、正文结构模板

### 模板1：种草测评型
适用：好物推荐、产品测评、使用体验分享

**结构：**
> 个人背景/痛点引出 → 产品基本信息 → 使用体验（分维度） → 优缺点总结 → 适合人群推荐 → 互动引导

**示例：**
```
✨ 干皮亲妈！这款面霜我已经空瓶3支了
👩 本人肤质：沙漠大干皮，换季必爆皮
💧 产品信息：xxx品牌 / xxx元 / 乳霜质地
📝 使用感受：
  🔹 保湿力：★★★★★ 涂完一整天不拔干
  🔹 吸收度：★★★★☆ 需要按摩一下
✅ 优点：保湿持久、不闷痘
❌ 缺点：包装一般
💡 适合干皮/混干皮姐妹
💬 你们冬天用什么面霜？
```

### 模板2：干货合集型
适用：技巧总结、清单推荐、知识科普（收藏率最高）

**结构：**
> 痛点共鸣 → 分点罗列（3-10个要点） → 收藏引导

**示例：**
```
📚 新手博主必知的8个运营技巧
刚开始做小红书踩了无数坑
今天把血泪教训整理出来👇
1️⃣ 选题跟着爆款走，不要自嗨
2️⃣ 标题一定要有数字，点击率高40%
3️⃣ 封面图要有文字，纯图片容易被划走
...
💾 建议收藏！反复看反复用
```

### 模板3：避坑/排雷型
适用：踩雷分享、消费提醒、经验教训

**结构：**
> 踩坑经历 → 具体问题描述 → 正确方法/替代方案 → 提醒建议

### 模板4：反派讨伐型
适用：纠正错误认知、科普正确方法

**结构：**
> 指出流行但错误的方法 → 展示3个具体危害 → 提出正确方案（步骤化）

### 模板5：场景共鸣型
适用：生活方式、情感类、个人成长

**结构：**
> 场景描写 → 情绪共鸣 → 产品/观点植入 → 价值升华

### 模板6：对比型
适用：效果展示、方法验证、产品对比

**结构：**
> 以前（错误/差） → 现在（正确/好） → 做对了什么 → 具体方法

## 三、抖音短视频文案结构

### 黄金3秒开头公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 扎心提问 | 「你是不是也…」 | 你是不是也发了几十条视频就几十个播放？ |
| 反常识 | 「90%的人都不知道」 | 90%做抖音的人都不知道，这个动作会让你限流 |
| 惊人结果 | 「我只用了XX天」 | 我只用了7天，从0涨粉到1万 |
| 悬念钩子 | 「我发现了XX的秘密」 | 我拆了100个爆款视频，发现了一个共同规律 |
| 制造焦虑 | 「2026年还不XX就晚了」 | 2026年还不做视频号，你将错过最后一波红利 |
| 直接利益 | 「XX教你XX」 | 3年运营总监教你，一条视频拿到10万播放 |

### 完整结构
> 钩子（前3秒） → 痛点场景（3-10秒） → 错误做法 → 正确方法 → 结果展示 → 引导互动

| 平台 | 风格 | 字数 | 核心逻辑 |

## 八、爆款笔记的共性规律

**1. 标题模型**
- 带数字的标题点击率高40%
- 有反常识观点的标题分享率高55%
- 直击痛点的标题收藏率高60%

**2. 正文结构**
- 痛点开头（前30%）→ 干货主体（50%）→ 结尾引导（20%）
- 每段不超过100字
- 善用换行、空格、emoji 制造呼吸感

**3. 互动设计**
- 评论区预埋3-5条引导评论
- 发布后2小时内快速回复每一条评论
- 在评论区补充笔记里故意留白的干货

**4. 视觉要求**
- 封面文字不超过15字
- 有核心关键词大字的封面，点击率高62%
- 真实感优于精修感
