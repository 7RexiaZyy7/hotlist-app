# 爆款文案框架完全指南

## 一、AIDA 框架（最经典）
适用：品牌广告、首页、新品推广

| 阶段 | 目的 | 写法 |
|------|------|------|
| Attention 注意 | 3秒内抓住眼球 | 反常识结论、扎心提问、惊人数据、强烈对比 |
| Interest 兴趣 | 让用户想继续看 | 展示场景、讲述故事、抛出悬念 |
| Desire 欲望 | 让用户想要 | 展示好处、证明价值、社会认同 |
| Action 行动 | 让用户马上下单 | 明确指令、制造紧迫感、降低门槛 |

**示例：**
> 注意：你的 SaaS 网站正在让你损失双倍月收入
> 兴趣：我可以帮你改变这一点
> 欲望：我帮助 SaaS 企业通过精准定位和清晰信息将访客转化为客户
> 行动：立即预约免费咨询

## 二、PAS 框架（最有效）
适用：痛点驱动型产品、直接转化、广告文案

| 阶段 | 目的 | 写法 |
|------|------|------|
| Problem 问题 | 指出用户的痛点 | "你是不是也遇到..." |
| Agitate 放大 | 让用户感到痛 | 描述不解决的后果、放大焦虑 |
| Solution 解决 | 给出方案 | 你的产品就是答案 |

**示例：**
> 问题：还在花 hours 手动做数据报表？
> 放大：每周浪费5小时在这些重复劳动上，你的团队效率正在被拖垮，竞品已经用自动化工具跑在了前面
> 解决：我们的插件工具，一键生成自动化报表，只需3秒

**示例2：**
> 问题：家里有异味，客人来了很尴尬
> 放大：传统清新剂只是遮盖气味，化学喷雾还有害健康
> 解决：FreshHome 从分子层面中和异味，24小时自动清新

## 三、FAB 框架（适合产品介绍）
适用：电商详情页、产品介绍、功能说明

| 阶段 | 说明 | 示例 |
|------|------|------|
| Feature 特征 | 产品有什么 | 这款手机配备了5000mAh电池 |
| Advantage 优势 | 比竞品好在哪 | 比同级手机多50%续航 |
| Benefit 利益 | 对用户意味着什么 | 出门不用带充电宝，一整天随便用 |

**核心：每个 Feature 都必须翻译成 Benefit。**

---

## 四、BAB 框架（讲故事型）
适用：案例展示、客户见证、品牌故事

| 阶段 | 写法 |
|------|------|
| Before 之前 | 用户之前有多痛苦/多差 |
| After 之后 | 用了你的产品后有多好 |
| Bridge 桥梁 | 你的产品如何帮他实现转变 |

**示例：**
> Before：以前发英文邮件要憋半天，每次写开发信都头皮发麻
> After：现在用 AI 写邮件，10分钟搞定50封，客户回复率翻倍
> Bridge：就是这个 AI 外贸工具，一键生成专业邮件

---

## 五、4Ps 框架（高转化型）
适用：高价产品、课程、服务类

| 阶段 | 说明 |
|------|------|
| Picture 画面 | 描绘用户理想状态 |
| Promise 承诺 | 明确承诺结果 |
| Proof 证明 | 数据/案例/背书 |
| Push 推动 | 限时/限量/独家 |

---

## 六、PASTOR 框架（深度说服型）
适用：教育类、咨询服务、高客单价

| 阶段 | 说明 |
|------|------|
| Problem 问题 | 定义问题 |
| Amplify 放大 | 放大痛苦 |
| Story 故事 | 讲故事建立连接 |
| Transformation 转变 | 展示转变后的美好 |
| Offer 报价 | 给出方案 |
| Response 回应 | 处理异议并推动 |

## 七、中文爆款文案结构（按场景）

### 短视频口播（抖音/视频号）
> 扎心开头（前3秒）→ 痛点场景 → 错误做法 → 正确方法 → 结果展示 → 引导互动

### 小红书图文
> 标题党（数字+结果）→ 场景代入 → 具体方法（步骤化）→ 总结金句 → 引导收藏

### 朋友圈文案
> 悬念开头 → 个人体验 → 价值输出 → 软性引导

### 公众号长文
> 故事开头 → 问题分析 → 核心观点 → 案例论证 → 金句收尾

## 八、钩子类型大全

| 类型 | 公式 | 示例 |
|------|------|------|
| 反常识 | "你以为XX，其实XX" | 你以为越努力越成功？其实方向比努力重要100倍 |
| 扎心提问 | "你是不是也..." | 你是不是也在纠结要不要换工作？ |
| 惊人数据 | "XX%的人不知道" | 90%的人不知道，这样发邮件回复率提高3倍 |
| 强烈对比 | "以前XX，现在XX" | 以前发100封没人回，现在发20封来3个询盘 |
| 悬念缺口 | "我发现了XX的秘密" | 我研究了100个爆款视频，发现了一个共同规律 |
| 场景代入 | "你有没有过这样的经历" | 你有没有凌晨3点还在改方案的经历？ |
| 权威背书 | "XX说/研究发现" | 哈佛研究发现，这样做效率提升200% |
| 制造焦虑 | "再不XX就晚了" | 2025年不做AI的人，将被时代淘汰 |

## 九、不同营销阶段的框架选择

| 阶段 | 推荐框架 | 目的 |
|------|----------|------|
| 认知期（TOFU） | AIDA、BAB | 吸引注意，建立认知 |
| 考虑期（MOFU） | PAS、PASTOR | 放大痛点，建立信任 |
| 决策期（BOFU） | FAB、4Ps | 展示价值，推动购买 |

## 十、框架组合技巧

高阶写法：一个文案里混合多个框架

**示例：**
> 【PAS 钩子】还在为写英文邮件发愁？（问题）
> 每次写开发信都要憋半天，客户还不回（放大）
> 【FAB 正文】我们的 AI 工具支持25种语言，一键生成专业邮件（特征）
> 比人工写快10倍，回复率提升3倍（优势）
> 每天省下2小时，可以多开发20个客户（利益）
> 【AIDA 结尾】现在注册送7天试用（行动）

## 附录：快速选择指南

- 用户知道痛点但不知道方案 → **PAS**
- 用户不知道产品值不值 → **FAB**
- 用户需要被教育 → **AIDA**
- 用户需要看到真实效果 → **BAB**
- 用户需要最后推一把 → **4Ps**
- 用户需要深度信任 → **PASTOR**
